# Priya Maurya · Portfolio

**Web Developer · EdTech & FinTech · AI-Native**

🔗 Live: **https://priyacoder01.github.io/portfolio/**

Personal portfolio built with HTML, CSS and JavaScript (no framework), hosted on GitHub Pages.

## Features
- Dark / light theme, fully responsive (mobile, tablet, desktop)
- Typing effect, scroll animations, animated stats, bento project grid
- Experience timeline, AI toolkit, certificate lightbox
- Contact form that opens the visitor's email app

## Folder structure
```
index.html                                   → main page
assets/css/style.css                         → all design
assets/js/main.js                            → animations, menu, theme
portfolio-responsive-complete-main/assets/img/  → all photos
```

## Changing a photo
Upload a new image to `portfolio-responsive-complete-main/assets/img/` with the **same file name**:

| On the site | File |
|---|---|
| Profile photo (round) | perfil.png |
| About photo | about.jpg |
| Projects | Gas.png, Fake.png, Dog.png |
| Achievements | A1.png, A2.png, A3.png |
| Certificates | c1.png, c2.png, c3.png |
| Resume button | Priya_Maurya_Resume.pdf (repo root) |
